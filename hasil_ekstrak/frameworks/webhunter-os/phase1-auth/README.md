# Pack A Part 1 — Authentication & Authorization

This package contains reasoning-oriented attack patterns for authentication
and authorization weaknesses used by WebHunter OS.

## Categories

### Authentication
- Broken Authentication
- Weak Password Policy
- MFA Weaknesses
- Password Reset Abuse
- Session Token Issues
- JWT Weaknesses
- OAuth / OIDC Misconfiguration

### Authorization
- Broken Access Control
- IDOR
- Missing Function-Level Authorization
- Missing Object-Level Authorization
- Privilege Escalation
- Role Confusion

Each pattern follows the same template:
- Overview
- Risk
- Common Root Causes
- Recon Indicators
- Discovery Strategy
- AI Reasoning Checklist
- False Positive Indicators
- Business Impact
- Related CWE / OWASP
