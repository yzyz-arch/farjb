# Attack Chains Framework

Chained attack methodologies for web2 and web3 bug bounty hunting.

## Components

### Attack Chain Web2
- Authentication bypass → privilege escalation chains
- IDOR → data exfiltration chains
- SSRF → internal network compromise
- Race condition → financial impact

### Attack Chain Web3
- Flash loan → price manipulation → liquidation
- Reentrancy → drain → token price crash
- Oracle manipulation → sandwich attack
- Access control → admin takeover → rug
